# Molecular Docking Analysis of Curcumin Against SARS-CoV-2 Main Protease (6LU7)

## Project Overview

This project focuses on molecular docking analysis of Curcumin against the SARS-CoV-2 Main Protease (6LU7) using AutoDock Vina and PyMOL.

The objective was to predict the binding affinity and analyze protein–ligand interactions using computational docking approaches.

---

## Tools Used

* AutoDock Vina
* AutoDock Tools (ADT)
* PyMOL
* OpenBabel

---

## Workflow

1. Protein preparation
2. Ligand preparation
3. PDBQT conversion
4. Grid box generation
5. Molecular docking using AutoDock Vina
6. Binding affinity analysis
7. Protein–ligand interaction visualization
8. Hydrogen bond analysis

---

## Protein Information

* Protein: SARS-CoV-2 Main Protease
* PDB ID: 6LU7

---

## Ligand Information

* Ligand: Curcumin

---

## Docking Results

| Ligand   | Binding Affinity (kcal/mol) |
| -------- | --------------------------- |
| Curcumin | -4.131                      |

---

## Result Interpretation

Curcumin showed weak to moderate binding affinity against the SARS-CoV-2 Main Protease. Multiple interacting amino acid residues and hydrogen bond interactions were observed near the binding pocket.
